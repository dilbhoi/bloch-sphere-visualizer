# 🔥 Bloch Sphere Visualizer

An interactive 3D visualization of qubit states using the Bloch Sphere representation.

---

## 🚀 Features
- 3D Bloch Sphere visualization
- Quantum gates: X, Y, Z, Hadamard
- Real-time state evolution
- Trajectory tracking of qubit state
- Dirac notation display
- Probability visualization

---

## 🧠 Concepts Covered
- Qubit representation
- Superposition
- Quantum gate operations
- Bloch sphere mapping

---

## 🛠 Tech Stack
- React
- Three.js
- React Three Fiber
